# Simple JS Clicker Game

**Simple JS Clicker Game** — это минималистичная браузерная игра-кликер с магазином улучшений, реализованная на чистом веб-стеке (HTML5, CSS3, Vanilla JS). Игроку предстоит зарабатывать монеты кликами, нанимать помощников и автоматизировать пассивный доход.

## 🚀 Особенности проекта

- **Двухпанельный интерфейс**: Экран разделен на две основные зоны — интерактивную область для кликов (45% ширины) и адаптивный магазин улучшений (55% ширины).
- **Внутриигровой магазин**: 8 уникальных улучшений (от «Новичка» до «Макуина» и «Профи»).
- **Разделение улучшений**:
  - **Активные (Multiplier)**: Увеличивают доход от каждого клика игрока (`+2`, `+8`, `+100`, `+1000`).
  - **Пассивные (Autoclicker)**: Автоматически генерируют монеты каждую секунду (`+1/сек`, `+10/сек`, `+75/сек`, `+100/сек`).
- **UX/UI оптимизация**:
  - Запрещено выделение текста (`user-select: none`), чтобы частые клики не приводили к случайному подсвечиванию элементов интерфейса.
  - Интерактивный отклик кнопок через CSS-псевдоклассы `:hover` (наведение) и `:active` (нажатие).
  - Карточки апгрейдов автоматически подстраиваются под размер экрана за счет процентной сетки.
- **Чистый код**: Реализовано без использования сторонних фреймворков или громоздких библиотек.

## 🛠️ Стек технологий

- **HTML5** — семантическая разметка игровых зон, структуры магазина и карточек товаров.
- **CSS3** — Flexbox-верстка, адаптивные размеры, кастомные шрифты семейства `Segoe UI`, скругления и стили интерактивности.
- **JavaScript (ES6+)** — логика обработки кликов, динамическое чтение данных из DOM-дерева, валидация баланса при покупках и цикличный таймер пассивного дохода.

## 🕹️ Игровая логика и устройство кода

- **Клик-механика**: По нажатию на левую панель (`#FrameClick`) скрипт берет текущее значение монет, парсит его в число и прибавляет к нему силу клика `ClickCoin` (базовое значение `1`).
- **Парсинг магазина**: При клике на покупку (`.BuyButtonUpgrade`) JS динамически определяет контекст через метод `.closest('.UpgradeFrame')`. Он автоматически считывает цену и размер бонуса прямо из текстового содержимого HTML-элементов карточки, что избавляет от необходимости жестко прописывать массивы данных в коде.
- **Пассивный доход**: С помощью `setInterval` каждую 1 секунду (1000 мс) проверяется счетчик автокликов `AutoCounterAdd`. Если он больше нуля, пассивные монеты автоматически добавляются к общему балансу.
